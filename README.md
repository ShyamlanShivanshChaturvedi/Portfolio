# 📱 Android Developer Portfolio App

A modern, native Android portfolio application built entirely with **Jetpack Compose**, following **Clean Architecture & MVVM**, with dependency injection powered by **Dagger Hilt** and backend services handled via **Firebase Authentication**.

---

## 🌟 Key Features

* 🔐 **Firebase Authentication**: Email/Password and OAuth sign-in flows with secure token and session handling.
* 🎨 **100% Jetpack Compose**: Pure declarative UI built with Material 3 components and dynamic theming.
* 🧱 **Clean Architecture + MVVM**: Strict separation of concerns between presentation, domain, and data layers.
* 💉 **Dagger Hilt**: Robust, compile-time dependency injection across ViewModels, repositories, and data sources.
* ⚡ **Reactive State Handling**: Unidirectional Data Flow (UDF) powered by Kotlin Coroutines, `StateFlow`, and `SharedFlow`.

---
